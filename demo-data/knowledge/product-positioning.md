# Product Positioning Playbook

## AgentOps Studio

AgentOps Studio is a **portable multi-agent operations lab**.
It demonstrates orchestration, RAG with citations, an MCP-style tool registry,
and run-level observability that you can start with Docker Compose.

Use Studio when you want:
- a hiring-manager demo path that works offline / free-stack
- transparent scaffolding for Docker, local Kubernetes, and Terraform blueprints
- a clear place to learn and extend multi-agent ops patterns

## Agent Fleet (separate product)

Agent Fleet is a **separate**, more complete multi-agent operations platform with
a live Contabo deployment. Do not conflate the two products in portfolios or CV copy.

Studio complements Fleet: Fleet is the fleets-at-scale product experience;
Studio is the open scaffold / ops lab for local demos and architecture storytelling.
