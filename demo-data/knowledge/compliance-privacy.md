# Compliance and Privacy Notes

## Public demo mode

Public demos must:
- use synthetic data only
- keep external actions sandboxed (draft / simulate)
- require human approval before any real write

## PII

Customer names, emails, phone numbers, and payment details are PII.
Do not paste PII into public Slack channels. Prefer redacted summaries.
If a workflow requests posting PII publicly, compliance residual risk is **high**.
