# Operations Runbook

## Executive daily brief

Every morning the ops workforce should summarize:
1. Support SLA risk (open Sev-1 / Sev-2)
2. Hiring pipeline movement
3. Product research priorities
4. Any compliance flags

The brief is posted to Slack `#exec-brief` only after human approval.

## Secrets

Never place API keys, customer PII, or private tokens into public channels.
Sandbox tools may simulate Slack/Gmail/GitHub writes without performing them.
